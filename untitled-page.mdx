# Courtroom Commands

This page outlines all available commands in Courtroom. Commands are split into **Global Commands** (accessible by everyone in public and private servers) and **Private Server Commands** (exclusive to private server hosts).

---

## Global Commands

These commands can be executed by **any player** on **any server** (Public or Private) to customize gameplay, switch teams, or optimize performance.

| Command | Syntax / Example | Description |
| :-- | :-- | :-- |
| **Join Team** | `/join <teamname>` | Switches your team. Supports abbreviations (e.g., `/join jury` for Juries, `/join sheriff` for Sheriff's Office). |
| **Low Graphics** | `/graphics` | Toggles Low Graphics Mode to boost FPS and smooth out performance during heavy lag. Type again to disable. |
| **Toggle Nametags** | `/nametag` | Toggles player nametags on and off. Ideal for taking clean screenshots or recorded footage. |

---

## Private Server Commands

These administrative tools are available exclusively in **Private Servers** to assist hosts in managing events, restricting team access, and keeping trials structured.

| Command | Syntax / Example | Description |
| :-- | :-- | :-- |
| **Admin Commands** | `:cmds / :commands` | Opens the external admin commands which includes all of the admin commands. |
| **Announce** | `/announce <message>` | Displays a prominent, server-wide announcement banner to all players. |
| **Toggle Barrier** | `/barrier` | Enables or disables the physical court barrier, separating the trial area from spectators to prevent disruptions. |
| **Ask to Join** | `/toggleasktojoin` | Toggles the approval system for team switches. When active, players requesting to switch teams must be approved or denied by the host. |
| **Lock Team Joins** | `/toggleteamjoins` | Disables or enables overall team joining. Useful when you want total control over assigning roles manually. |

### Protected Teams & Approvals

<Note>
  **Restricted Roles:**<br />Certain high-authority teams — specifically **Judges** and **Sheriff's Office** — always require administrative approval before a player can join them.
</Note>

<Warning>
  The **Administration Team** is reserved solely for the private server host. It cannot be joined via public commands or requested through the approval system.
</Warning>
